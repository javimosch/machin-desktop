Native desktop apps in machin.
One draw call. State that survives every edit.

A typed, GPUI-style UI written in machin (MFL), drawn on the GPU in a single instanced draw per frame — with hot reload that keeps the window open and your state intact while you edit.

The whole app

{{example_html}}

The view is a function of state, run every frame. state_int reads a value owned by the host process — so it survives every reload. button() returns true on the frame it is clicked. That's the model; layout covers the rest.

./mdk new apps/hello      # scaffold
./mdk dev apps/hello      # window opens; edit app.src and save — it redraws in place
./mdk build apps/hello    # one 2.6 MB release binary
