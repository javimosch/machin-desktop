Internals

Two halves joined by a plain C ABI: an MFL framework that builds and lays out the tree, and a C host that owns the window, the GPU, the text and everything that must outlive a reload.

The frame

  1. The host swaps its two element buffers (this frame's becomes last frame's), clears the instance buffer and the per-frame string pool, and calls mfl_mdk_frame_0.
  2. mdk_frame (MFL, inside arena { }) runs ui_begin() → your view() → ui_end().
  3. ui_end(): measure(0, window_w) bottom-up with width constraints top-down, place(0, 0, 0, w, h) top-down, paint() in creation order calling mdk_rect / mdk_shadow / mdk_text, then mdk_set_n.
  4. The host uploads the instances and issues one glDrawArraysInstanced(GL_TRIANGLE_STRIP, 0, 4, n).

Frames run only when something changes: an event, a reload, a pending build error change, or animate(). A release build waits in SDL_WaitEvent with no timeout — zero wake-ups at rest.

Element records

The tree is fixed-stride records in host-owned memory, read and written from MFL with peek_*/poke_*. No MFL allocation per element, no per-frame garbage, and the previous frame's buffer — which hover/press/click test against — survives a reload because the host owns it.

Records are 160 bytes; the host gives 256-byte slots × 65,536 elements per buffer, calloc'd so untouched pages cost nothing.

The renderer

Every primitive is one 80-byte instance: rect (x, y, w, h), atlas uv, fill and border colors, radius, border width, kind, blur. One vertex shader expands each instance into a quad; one fragment shader branches on kind:

  • rect — a rounded-box signed distance gives antialiased corners at any scale; the border is a second distance band mixed in.
  • shadow — the same distance field, smoothstepped over the blur radius.
  • glyph — coverage sampled from an R8 atlas, tinted.

Painting order is draw order, so parents land under children with no depth buffer. Blending is premultiplied-style SRC_ALPHA, ONE_MINUS_SRC_ALPHA.

Text

  • Faces: a regular and a bold face found from known system paths (then fc-match; override with MDK_FONT / MDK_FONT_BOLD).
  • Shaping cache: each (string, pixel size, face) is shaped once with HarfBuzz into a run — glyph ids, advances, offsets, and break opportunities at spaces — kept in an 8,192-slot hash table (cleared wholesale when ¾ full).
  • Wrapping: greedy over cached advances, so rewrapping the same text at a new width never re-shapes. Lines below the window are not emitted.
  • Atlas: 1024² R8, glyphs rasterized by FreeType on first use, uploaded by dirty row range; when full it resets after the frame and refills on demand.

Host ABI

The framework declares these in a headerless extern "mdk" { … } block; the dev host is linked -rdynamic so the app's .so resolves them against the executable at dlopen; the release links them directly.

Strings cross as const char*; the host copies what it keeps (mdk_str returns a handle into a per-frame pool), so no MFL string outlives its frame arena.

How an MFL module becomes a .so

A machin program with no main and an export func mdk_frame() emits a non-static C symbol mfl_mdk_frame_0 and no int main. cc -shared -fPIC -std=c11 -fno-strict-aliasing -fwrapv turns that into a loadable module whose runtime works without main. -std=c11 matters: GNU mode predefines unix, which collides with a parameter name in machin's prelude.

Test hooks

  • --shot out.ppm --frames N — render N frames and write the framebuffer.
  • --click X Y (repeatable) — queue real SDL motion/press/release events, one click per two frames.
  • SIGUSR1 — save the next frame to $MDK_SHOT without stopping.
  • MDK_BENCH=1 with BENCH_WARMUP/BENCH_FRAMES — MyGo's recorder protocol on stdout.
